# Drakopal: feedback

This is the place to tell us what you think of [Drakopal](https://www.curseforge.com/minecraft/mc-mods/drakopal), a
free Fabric mod where you hatch a dragon from an egg and raise it. The mod's code is not here; only your feedback is.

**[Open a new issue](../../issues/new/choose)** and pick one:

- **I like it / I don't like it**: what was fun, what was boring or confusing. Short is fine.
- **Bug**: something broke or looks wrong.
- **Idea**: what should the dragon learn next?

Please write **no personal data**: no real names, ages, school, address, or photos of people. Screenshots of the game
are welcome. A GitHub account needs you to be 13 or older; younger players can ask a parent to write for them, or
send an e-mail to **michal@kukla.tech**.

Made by a dad for his kids. Every issue is read; replies may take a few days.
